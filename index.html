You can upload the Excel file exported directly from Framecad Detailer — frame groups will be detected automatically. Alternatively, use the CSV template for manual data entry. Include (WELD) in a frame name to exclude it from packing. Length >3400mm will auto-rotate. All values rounded to nearest 10mm.

Tab-separated (copy from Excel), comma or semicolon also accepted. Header row auto-detected.

How to use this report

  1. Fill in the Job details at the top — job title, sub-heading, project number and work order.
  2. Import your frame data using the Import file tab, or enter frames manually.
  3. Set the Max layers per pack based on frame size (see reference table).
  4. Click Build packs to generate the packing layout.
  5. Review the results, then click Export PDF to print the report.

How to use the template

  1. Download the CSV template using the button in the Import file tab.
  2. Export the Excel file from your detailer software.
  3. Copy the frame names and paste into the Name column.
  4. Copy Max Height and paste into the Height (mm) column — paste values only.
  5. Copy Max Length and paste into the Length (mm) column — paste values only.
  6. Save the file.
  7. Upload the file using the Import file tab.
  8. To exclude a frame from packing, add (WELD) to the frame name — e.g. Frame A (WELD). This is case sensitive and the brackets must be included.
